# Changelog

## 0.1.0

The first published version.

- Diagnostics, completion and semantic colouring from `swordls`.
- A TextMate grammar for when the server is not attached.
- *Sword: Run File*, *Sword: Run Tests in Package*, and a **run test** link above
  each test.
- Snippets for `func`, `method`, `main`, `test`, `scope`, `lock`, `switch`,
  `select` and `error`.
- Indentation for brackets, `case` and `default`, and block comments.
- A warning, once, when `swordls` or `shield` cannot be found.
